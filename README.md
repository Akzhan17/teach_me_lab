# Teach Me

Teach Me — оқу материалынан автоматты түрде сұрақ-жауап карточкаларын жасайтын Django веб-қосымшасы.

Жоба пайдаланушыға мәтіндік материалды енгізуге, одан карточкалар алуға, жауаптарды бастапқы мәтінмен салыстыруға және карточкалардың тексерілу мәртебесін басқаруға мүмкіндік береді.

## Мүмкіндіктері

- Оқу материалының атауы мен мәтінін енгізу.
- Материалдан үш сұрақ-жауап карточкасын жасау.
- DEMO режимінде дайын мысал деректерін пайдалану.
- LIVE режимінде Gemini API арқылы карточкалар генерациялау.
- Карточканың сұрағын, жауабын және бастапқы мәтіннен алынған дәйексөзін редакциялау.
- Дәйексөздің бастапқы мәтінде бар екенін тексеру.
- Карточканы жеке өшіру.
- Карточканы тексерілген немесе тексерілмеген деп белгілеу.
- Барлық, тексерілген және тексерілмеген карточкаларды сүзу.
- Карточкалардың жалпы санын және мәртебе бойынша санын көрсету.

## Технологиялар

- Python
- Django
- SQLite
- python-dotenv
- Google Gemini API (LIVE режимі үшін)
